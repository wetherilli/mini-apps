# mini-apps

브라우저에서 바로 돌아가는 작은 앱들을 한 저장소에 모아 둡니다.
빌드 도구도, 설치할 것도 없습니다 — `index.html` 을 열면 그대로 돌아갑니다.

## 구조

```
index.html          앱 목록 — 여기서 각 앱으로 들어갑니다
apps/<앱이름>/       앱 하나. 저마다 독립입니다
  index.html          화면
  app.js              동작
  README.md           이 앱이 무엇인지 한 줄
  assets/             (쓸 때만) 그림·소리
apps/_틀/            새 앱을 만들 때 베껴 쓰는 빈 틀
tools/판올리기.js     앱의 판 번호를 올립니다 (캐시 갈이)
.claude/launch.json  미리보기 서버 설정 (python http.server :8766)
```

앱끼리 코드를 나눠 쓰지 않습니다. 한 앱을 고쳐도 다른 앱은 건드리지 않습니다 —
작은 앱을 여럿 두는 저장소에서는 그것이 가장 싸게 먹힙니다.

## 미리보기

`file://` 로 열어도 대개 돌아가지만, 쪽 파일을 불러오는 앱은 서버가 있어야 합니다.

```bash
python -m http.server 8766 --bind 127.0.0.1
```

그 다음 http://127.0.0.1:8766/ 을 엽니다. Claude Code 에서는 `.claude/launch.json` 의
`mini-apps` 설정이 같은 일을 합니다.

## 새 앱 만들기

1. `apps/_틀/` 을 `apps/<앱이름>/` 으로 베낍니다.
2. `index.html` 의 `<title>` 과 `<h1>` 을 고칩니다.
3. 그 앱 `README.md` 에 무엇을 하는 앱인지 한 줄 적습니다.
4. 뿌리 `index.html` 의 앱 목록에 한 줄 더합니다.
5. 틀이 들고 있는 `?v=1.0.0` 과 `const VERSION` 은 그대로 둡니다 — 아래 「판 올리기」.

```bash
cp -r apps/_틀 "apps/<앱이름>"
```

## 판 올리기

브라우저는 주소가 같으면 **받아 둔 옛 파일을 한참 더 씁니다.** 고쳤는데 휴대폰에서
안 바뀌어 보이는 까닭이 그것입니다. 그래서 앱마다 쪽 파일을 판 번호와 함께 부릅니다 —
`<script src="app.js?v=1.0.3">`. 판이 오르면 주소가 갈리므로 새 파일을 받습니다.

앱을 고쳤으면 **같은 작업 안에서** 올립니다. Claude 와 함께 고칠 때는 **Claude 가 스스로
돌립니다** — 시키지 않아도 됩니다. 아래는 혼자 고칠 때 쓰는 명령입니다.

```bash
node tools/판올리기.js 링크서랍
```

| 쓰는 꼴 | 하는 일 |
|---|---|
| `node tools/판올리기.js 링크서랍` | 끝자리 +1 (1.0.0 → 1.0.1) |
| `node tools/판올리기.js 링크서랍 가운데` | 가운데 +1 (1.0.3 → 1.1.0) |
| `node tools/판올리기.js 링크서랍 앞` | 앞자리 +1 (1.1.2 → 2.0.0) |
| `node tools/판올리기.js 링크서랍 2.3.0` | 그 번호로 |
| `node tools/판올리기.js --모두` | 앱을 전부 끝자리 +1 |

`index.html` 의 `?v=` 와 `app.js` 의 `const VERSION` 을 함께 맞춥니다.
판은 **화면 맨 아래에 떠 있습니다** — 휴대폰에서 고친 것이 안 보이면 거기부터 보십시오.
번호가 옛것이면 캐시가 묵은 것이니 강제 새로 고침을 하면 됩니다.
