# 링크서랍

링크를 모아 두고, 손수 단 태그로 꺼내 보는 앱.

## 쓰는 법

- **＋** 로 링크를 넣습니다. 주소만 적어도 됩니다(`https://` 는 저절로 붙습니다).
  제목을 비우면 주소의 도메인이 제목이 됩니다. 태그는 **쉼표로** 나눕니다.
- 태그 단추를 눌러 걸러 냅니다. **여럿을 고르면 그 태그를 모두 가진 것**만 남습니다.
- 찾기 칸은 제목·주소·메모·태그를 한꺼번에 뒤집니다.
- 태그를 걸어 둔 채로 ＋ 를 누르면 그 태그가 미리 채워집니다.

## 링크를 누르면 — 시크릿 탭에 대하여

누르면 **일반 새 탭**에서 엽니다. 시크릿 탭으로 여는 길은 사용자가 직접 고르는 것뿐입니다 —
휴대폰은 링크를 **길게 눌러**, PC 는 **우클릭해서** 「시크릿 탭에서 열기」를 고릅니다.

웹페이지가 시크릿 탭을 코드로 여는 길은 없습니다(브라우저가 막습니다).
그 일을 할 수 있는 것은 크롬 **확장**의 `chrome.windows.create({incognito: true})` 뿐이고,
그것도 사용자가 확장 설정에서 「시크릿 모드에서 허용」을 켜 둬야 하며 **안드로이드 크롬에는
확장이 없습니다.** 그래서 이 앱은 웹앱으로 두고, 제목을 **진짜 `<a href>`** 로 세워
브라우저 자신의 길게 누르기 메뉴를 살려 두었습니다.

> 고칠 때 주의 — 제목을 단추로 바꿔 JS 의 `window.open` 으로 열면 그 메뉴가 사라집니다.
> CSS 의 `-webkit-touch-callout: none` 도 길게 누르기를 죽입니다. 둘 다 쓰지 마십시오.

## 자료가 사는 곳

실제 저장은 이 브라우저의 `localStorage` 입니다(열쇠 `링크서랍.자료`).
`data.js` 는 **저장이 비어 있을 때만** 읽는 처음 자료입니다.

웹페이지는 자기 폴더의 파일을 고쳐 쓸 수 없습니다. 그래서 둘을 이렇게 잇습니다 —

| 하는 일 | 어떻게 |
|---|---|
| 다른 기기로 옮기기 · 저장소에 넣기 | **「data.js 로 내보내기」** → 받은 파일을 `apps/링크서랍/data.js` 에 덮고 커밋 |
| 내보낸 파일 되읽기 | **「파일에서 불러오기」** — 내보낸 `data.js` 도, 맨 JSON 도 받습니다 |
| 이 브라우저에 쌓은 것 버리기 | **「처음 자료로 되돌리기」** — `data.js` 의 자료로 돌아갑니다 |

불러오기는 파일 안의 코드를 돌리지 않습니다(`eval` 을 쓰지 않고 JSON 만 떼어 읽습니다).

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면과 꾸밈 |
| `app.js` | 읽고 쓰기 · 태그 거르기 · 내보내기/불러오기 |
| `data.js` | 처음 자료 (`window.LINKS_SEED` 배열) |

`data.js` 의 한 줄은 이렇게 생겼습니다.

```js
{
  "url":   "https://www.algaebase.org/",
  "title": "AlgaeBase",
  "tags":  ["규조", "도감"],
  "note":  "학명 유효성 확인",
  "added": "2026-10-26"
}
```
