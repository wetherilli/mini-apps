# 링크서랍

링크를 모아 두고, 손수 단 태그로 꺼내 보는 앱.

## 화면 두 벌

**목록** — 카드 한 장이 링크 하나입니다. **제목 줄**과, 그 아래 **별점과 태그가 나란히 선 줄**
두 줄입니다. 주소는 카드에 적지 않습니다(속성 화면에 있습니다). 태그는 **세 개까지** 보이고
넘치면 `+N` 으로 적힙니다.

| 하는 짓 | 되는 일 |
|---|---|
| 카드를 **누르기** | 그 링크의 **속성** 화면으로 들어갑니다 |
| 카드를 **꾹 누르기** | **여러 개 고르기**로 들어갑니다. 이어서 탭으로 더 고릅니다 |
| 제목을 **꾹 누르기** | 브라우저 메뉴 — 여기서 **「시크릿 탭에서 열기」** |
| **별**을 누르기 | 그 자리에서 별점을 먹입니다. 먹인 별을 다시 누르면 0 으로 |
| 오른쪽 위 **편집** | 카드의 별점·태그 자리가 **🗑 지우기** 로 바뀝니다 |
| 왼쪽 위 **정렬 단추** | 누를 때마다 **넣은 순 → 별점 높은 순 → 별점 낮은 순** 으로 돕니다 |
| 태그 단추 | 걸러 보기. 오른쪽 끝에 **몇 개가 걸렸는지** 적힙니다 |
| 찾기 칸 | 제목·주소·메모·태그를 한꺼번에 뒤집니다 |

**속성** — 주소는 `#/l/<id>` 입니다. 뒤로 가기가 그대로 듣습니다.
제목 · **링크 줄** · **별점 줄**(큼직한 별 다섯) · 태그 · 메모 · 넣은 날을 보고,
「고치기」로 그 자리에서 고칩니다. 태그를 누르면 그 태그로 걸러 본 목록으로 돌아가고,
**＋ 태그** 로 더 답니다.

## 별점

0~5 점입니다. **0 은 「안 먹였다」** 이고, 먹인 별을 다시 누르면 0 으로 돌아갑니다.
목록 카드에서도, 속성 화면에서도 바로 누릅니다. 여러 개 고르는 중에는 별을 눌러도
별점이 바뀌지 않고 **고르기가 먼저** 듣습니다 — 안 그러면 고르다가 별점을 엎습니다.
내보낸 `data.js` 에도 `star` 로 함께 나갑니다.

## 태그 여러 개 겹쳐 보기

태그 단추를 여럿 누르면 **두 개째부터** 정렬 단추 옆에 모드 단추가 뜹니다.

| 모드 | 남는 것 |
|---|---|
| **모두 가진 것** (기본) | 고른 태그를 **다** 가진 링크만 |
| **하나라도 가진 것** | 고른 태그 중 **하나라도** 가진 링크 |

정렬과 이 모드는 `localStorage` 의 `링크서랍.보기` 에 따로 남아, 다음에 열 때도 그대로입니다.

## 링크를 여는 길은 길게 누르기 하나뿐입니다

**그냥 눌러서는 링크가 열리지 않습니다**(사용자 지침 2026-10-26 — 쉽게 일반 탭에 열리는
것이 싫다). 탭은 속성 화면으로 가고, 링크는 **길게 누르거나(휴대폰) 우클릭해서(PC)**
브라우저 메뉴의 「시크릿 탭에서 열기」로 엽니다.
목록에서는 **제목 줄**, 속성 화면에서는 **링크 줄**이 그 자리입니다.

웹페이지가 시크릿 탭을 코드로 여는 길은 없습니다(브라우저가 막습니다). 그 일을 할 수 있는
것은 크롬 **확장**의 `chrome.windows.create({incognito: true})` 뿐이고, 그것도 사용자가
「시크릿 모드에서 허용」을 켜 둬야 하며 **안드로이드 크롬에는 확장이 없습니다.**
그래서 웹앱으로 두고, 제목·주소를 **진짜 `<a href>`** 로 세워 브라우저 자신의 메뉴를
살리되 `click` 만 막았습니다.

> **고칠 때 주의**
> - `<a href>` 를 단추로 바꾸거나 JS 의 `window.open` 으로 열면 그 메뉴가 사라집니다.
> - CSS 에 `-webkit-touch-callout: none` 을 걸어도 길게 누르기가 죽습니다.
> - `click` 만 막고 **`contextmenu` 는 건드리지 마십시오.**

**꾹 누르기가 두 가지인 까닭** — 제목 줄 위에서는 브라우저 메뉴(시크릿), 그 밖의 카드
자리에서는 여러 개 고르기입니다. 자리를 나눠야 둘 다 삽니다.

## 여러 개 고르기

카드를 꾹 눌러 들어가면 아래에 바가 뜹니다. 탭으로 더 고르고 **「태그 넣기」** 를 누르면,
고른 **모두에게 한꺼번에** 태그를 답니다. 추천 칩을 여럿 눌러도 되고, 아래 칸에 쉼표로
새 태그를 적어도 됩니다. 이미 달린 태그는 겹쳐 들어가지 않습니다.

## 태그 추천

태그를 적는 자리(넣기·고치기·태그 넣기)에는 **지금 자료에서 많이 쓴 태그부터** 칩으로
깔립니다. 같은 횟수면 가나다순입니다. 눌러서 넣고, 다시 눌러서 뺍니다.

## 자료가 사는 곳

실제 저장은 이 브라우저의 `localStorage` 입니다(열쇠 `링크서랍.자료`).
`data.js` 는 **저장이 비어 있을 때만** 읽는 처음 자료입니다.

웹페이지는 자기 폴더의 파일을 고쳐 쓸 수 없습니다. 그래서 둘을 이렇게 잇습니다 —

| 하는 일 | 어떻게 |
|---|---|
| 다른 기기로 옮기기 · 저장소에 넣기 | **「data.js 로 내보내기」** → 받은 파일을 `apps/링크서랍/data.js` 에 덮고 커밋 |
| 내보낸 파일 되읽기 | **「파일에서 불러오기」** — 내보낸 `data.js` 도, 맨 JSON 도 받습니다 |
| 이 브라우저에 쌓은 것 버리기 | **「처음 자료로 되돌리기」** — **두 번 눌러야** 합니다. 첫 번째 누름은 단추 글을 「정말요? 한 번 더」로 바꿀 뿐이고, **5초** 안에 다시 눌러야 지웁니다. 그냥 두면 저절로 풀립니다 |

불러오기는 파일 안의 코드를 돌리지 않습니다(`eval` 을 쓰지 않고 JSON 만 떼어 읽습니다).
처음 자료를 읽을 때 `id` 를 붙여 **바로 저장해 둡니다** — 그래야 속성 화면 주소가
새로 고칠 때마다 달라지지 않습니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 두 화면의 뼈대와 꾸밈 |
| `app.js` | 저장·거르기·꾹 누르기·여러 개 고르기·속성 화면·내보내기/불러오기 |
| `data.js` | 처음 자료 (`window.LINKS_SEED` 배열) |

`data.js` 의 한 줄은 이렇게 생겼습니다(`id` 는 없어도 됩니다 — 없으면 처음 열 때 붙습니다).

```js
{
  "url":   "https://www.algaebase.org/",
  "title": "AlgaeBase",
  "tags":  ["규조", "도감"],
  "star":  4,
  "note":  "학명 유효성 확인",
  "added": "2026-10-26"
}
```

`star` 가 없으면 0 입니다. 옛 `data.js` 를 그대로 불러와도 됩니다.

## 크기에 대하여

본문 13px, 누르는 자리 36px(작은 단추 30px · 태그 칩 28px)입니다 — 사용자 지침
2026-10-26 으로 글자와 함께 줄였습니다. **터치 권장치는 44px 이니 여기서 더 줄이지
마십시오.** 더 좁혀야 하면 글자나 단추가 아니라 여백(`li.row` 의 padding, `.mini` 의
gap)을 건드리는 쪽이 낫습니다.

주소 칸은 `type="url"` 이 아니라 `type="text"` 입니다 — `diatoms.org` 처럼 적은 것을
브라우저가 막아 버리기 때문입니다. `https://` 는 저장할 때 붙입니다.
